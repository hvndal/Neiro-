# neiro — design review, 2026-11-25

Method: [PROMPT.md](PROMPT.md). Build under review: commit `8e198b2` (all five screens + living wash and shader lens).
Evidence tags: **seen** = visible in a web render, **code** = read in source, **unverified** = needs a phone, GPU or speakers.
References actually viewed: Dark Noise (MacStories review screens, 3.2 widget screenshots, App Store listing text), Blankie and Moodist (repos). Mobbin was unavailable (paid plan), so no Mobbin screens were used.

## 1. Verdict

neiro has a distinctive look and a strong idea (the screen *is* the colour), but today it is a **silent, partly static mock-up**: it makes no sound, its main dial cannot be turned, and three of its five screens abandon the colour identity. It is not close to a $200k/month app yet; the single biggest reason is that **the core loop (turn the dial, hear the colour change) does not exist**. Everything below is ordered by that.

## 2. Per-screen review

### Play
| | |
| --- | --- |
| **Job** | One tap to sound; one gesture to change colour; see what is playing. |
| **Ideal** | Dark Noise: one control, instant sound, state obvious, controllable from anywhere. Endel-style: the screen visibly *breathes* while it plays. |
| **Current** | Pink wash that flows (`seen`, wash luminance range ≈ 9–12 levels); shader glass lens with refraction and highlight (`seen`, software GL only); 7 dots on an arc; volume arc; play/pause toggles a flag (`code`). |
| **Gap** | (1) **The dial does not turn**: only the dots are tappable, there is no rotate gesture, no detents, no haptic ticks, no inertia, yet the caption says "turn to change colour" (`code`). (2) Volume arc is decorative, not draggable (`code`). (3) "sleep timer" and "+ mix" pills do nothing (`code`). (4) No sound (`code`). (5) Locked dots are just 60 % opacity, no lock cue (`seen`). (6) Unselected dot tap area is 14 + 2×14 hitSlop = **42 pt, under the 44 pt minimum** (`code`). (7) Playing state is subtle: the wash speeds up but nothing else changes (`unverified` on device). |
| **Why not yet** | Layout-first build order; behaviour (gesture, audio) comes in the audio and interaction steps. The caption is aspirational copy written before the gesture existed. |
| **Fix** | Pan-gesture dial with detent snap (spring damping ≈ 18, stiffness ≈ 220), `selection` haptic per detent, `rigid` + Pro sheet on locked; draggable volume arc; real timer sheet; enlarge dot hit area to ≥ 44 pt. **M** |

### Study
| | |
| --- | --- |
| **Job** | Start a focus block in two taps; know exactly when the next break comes. |
| **Ideal** | A timer that is real, with idle, running, break and finished states, plus a label for what you are working on. |
| **Current** | Static "18:42", "2 of 4" bars, five mode chips, restart/pause/skip (`seen`). Chips wrap onto three rows and crowd the controls (`seen`). Only the *running* state is designed. |
| **Gap** | Timer is fake; no idle/start state; no break or finished state; no task label; chip rows cramped; 8 px between pause button and tab bar feels tight (`seen`). |
| **Why not yet** | Real timers are a separate step (timestamp-based, notifications); the canvas only drew one state. |
| **Fix** | Timestamp timer + notifications, state machine (idle → focus → break → done), horizontally scrolling chip row, colour crossfade to the break colour (spec §9). **M** |

### Programs
| | |
| --- | --- |
| **Job** | Pick a ready-made night or focus session and start it. |
| **Ideal** | A preview of the journey (a colour timeline), clear duration, favourites, and a persistent Now Playing bar (Dark Noise has one). |
| **Current** | Six white cards with overlapping colour dots, a pro chip or play glyph (`seen`). A back button sits on a tab screen, which is redundant (`seen`). "nap 20" has one dot, so its text sits further from the left edge than the other cards (`seen`). |
| **Gap** | Tapping a free card just switches to Play and starts nothing (`code`); no timeline preview; no favourites; no way to see what is running. White cards on a pale wash make this the flattest screen. |
| **Why not yet** | Programs engine is a later step; the card list is a faithful copy of the canvas. |
| **Fix** | Tinted (not glass) cards, a mini colour timeline per card, start-with-confirmation, Now Playing pill above the tab bar, drop the back button. **M** |

### Customise
| | |
| --- | --- |
| **Job** | Make the app feel like *yours*, and want Pro. |
| **Ideal** | Live preview: change the dial finish or grain and see it applied on a real dial immediately. |
| **Current** | Icon grid, finish swatches, grain segmented control, "unlock with pro" (`seen`). Selection state works locally; nothing applies anywhere (`code`). |
| **Gap** | No live preview, so nothing to *want*; alternate app icons need native config that is not done; finish and grain have no effect on Play. |

### Pro sheet
| | |
| --- | --- |
| **Job** | Convert. This screen is the revenue. |
| **Ideal** | Price and primary button visible without scrolling on every device; the user can **hear** a locked colour before buying; trust line near the button. |
| **Current** | Ring, "neiro pro", four locked colours, six perks, "unlock for $4.99", restore, tip row (`seen`). On an 844-pt screen the button sits at ≈ 710 pt (visible) but the tip row is cut off; on a 667-pt phone the button would be below the fold (`seen` + arithmetic). Locked colours are static dots. Button does nothing (`code`). |
| **Gap** | No audition of locked colours (the strongest conversion lever for a sound product); button not sticky; no price skeleton or store state; no "pay once" proof near the button; no credits for CC-BY sounds yet. |
| **Why not yet** | IAP and store-price loading are step 8. |
| **Fix** | Sticky bottom CTA, 10-second audition on each locked colour (tap a dot → hear it with a fade), price skeleton, restore. **M** |

## 3. Cross-cutting issues

1. **Identity breaks on 3 of 5 screens.** Play and Study are full-bleed colour; Programs, Customise and Pro are paper and white. The spec's core idea ("the screen becomes the colour") disappears exactly where users browse and pay. *Fix: every screen takes a tinted wash of the current noise; cards stay solid.* **S–M**
2. **Nothing persists across tabs.** Start a sound, switch to Programs, and there is no sign it is playing and no control. Dark Noise's Now Playing bar solves this. *Fix: a glass mini-player above the tab bar.* **S**
3. **Motion is only the wash.** Spec §9 (launch ring draw, staggered reveals, detent springs, grain drift, skeleton for the store price) is not built. *Skeletons belong only where there is real waiting (the price); everywhere else use staggered reveals.* **M**
4. **Glass is unproven.** On iOS 26 the native material should work over the shader wash; this has never been seen on a device (`unverified`). The web fallback is only a stand-in.
5. **States are missing everywhere:** timer finished, audio interrupted (call, headphones unplugged), purchase failed, restore with nothing to restore.
6. **Contradiction to resolve:** the handover says no analytics and no tracking; the decision taken in chat is full product analytics. Privacy copy, App Store labels and the Pro screen's trust line must match whichever is true.

## 5. Ranked backlog

**P0 (blocks "it is an app" or revenue)**
1. Audio engine: seamless loops, 1.2 s crossfades, background play, interruptions. *Accept:* tap play, hear pink; turn to brown with no click; lock the phone, sound continues.
2. Rotatable dial with detents, haptics, inertia, locked-colour rigid haptic. *Accept:* one-thumb drag across all 7 colours with a tick each.
3. Now Playing mini bar on all tabs. *Accept:* play on Play, open Programs, pause from there.
4. Pro: sticky CTA, locked-colour audition, price skeleton, restore, credits link. *Accept:* a free user can hear violet for 10 s then see the price without scrolling on a 667-pt phone.
5. Settings with credits and privacy.

**P1 (depth and retention)**
6. Coherence pass: tinted wash on Programs / Customise / Pro.
7. Real Study timer with idle, break and finished states.
8. Texture layers (rain, fan, stream…) from the CC0 set, mixable.
9. Sleep mode.
10. Lock screen, widget, Control Centre, Siri, Live Activity.

**P2 (polish)**
11. 44 pt dot targets and lock glyphs; remove the back button on tabs; programs timeline preview; Customise live preview; launch animation and staggered reveals; localisation (音色 is a hook for Japan).
